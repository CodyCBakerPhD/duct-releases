# Compiled executables for `con-duct` releases

Compiled executables of `con-duct`.


## Usage

In general, to easily download the binary run:

```bash
curl -L -O https://github.com/codycbakerphd/duct-releases/releases/download/[ RELEASE VERISION ]/con-duct_[ RELEASE VERSION]_[ PLATFORM ]
```

### Linux

For example, to download `v0.18.0`:

```bash
curl -L -O https://github.com/codycbakerphd/duct-releases/releases/download/v0.18.0/con-duct_v0.18.0_linux
```

then 

```bash
chmod +x con-duct_v0.18.0_linux
```

to give executable permissions, then:

```bash
./con-duct_v0.18.0_linux --help
```

should behave identically to a local Python installation of the `con-duct` entrypoint!
